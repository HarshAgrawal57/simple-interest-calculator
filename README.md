# Simple Interest Calculator

A simple web application that calculates simple interest based on the principal amount, annual interest rate, and number of years.

## Features

- Input fields for principal amount, rate of interest, and number of years
- Calculates simple interest using the formula below
- Displays the interest amount and the maturity year
- Validates input so the principal must be a positive number

## Formula

Simple Interest = (P x R x T) / 100

- P = Principal amount
- R = Annual rate of interest (%)
- T = Time in years

## Example

| Principal | Rate | Years | Interest |
|-----------|------|-------|----------|
| 1000      | 5%   | 2     | 100      |

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Clone this repository
2. Open `index.html` in a web browser
3. Enter the principal, rate, and number of years
4. Click **Compute Interest** to see the result
