# Contributing to Simple Interest Calculator

Thank you for your interest in contributing! All contributions are welcome, including:

- Bug reports
- Bug fixes
- Documentation improvements
- Enhancements
- Ideas

## How to Contribute

1. Fork this repository.
2. Create a new branch for your change (`git checkout -b my-change`).
3. Make your changes and commit them with a clear message.
4. Push the branch to your fork.
5. Open a pull request describing what you changed and why.

## Reporting Bugs

Open an issue and include:

- A short description of the problem
- Steps to reproduce it
- What you expected to happen and what actually happened

## Suggesting Enhancements or Ideas

Open an issue describing your idea and how it would improve the calculator.

## Code of Conduct

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.
